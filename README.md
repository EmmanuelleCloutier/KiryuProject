### Description

Moteur physique réalisé dans le cadre du cours de Mathématique et physique pour le jeu vidéo


### Architecture du projet

| Composant        | Rôle                                                                           |
|------------------|--------------------------------------------------------------------------------|
| `Game`           | Exemple de jeu utilisant le moteur physique                                    |
| `KiryuEngine`    | Le moteur Physique                                                             |
| `ProcessingCore` | Utilisation de la plateforme processing afin de facilité la partie "Rendering" |
| `Tests`          | Tests Unitaires                                                                |
